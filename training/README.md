# Custom KWS Training Pipeline

This folder contains a fully local, 7-stage pipeline to generate, augment, split, train, and test a Custom Keyword Spotting (KWS) Neural Network for STM32 deployment.

## Prerequisites & Installation

To ensure portability and avoid polluting your system Python, create a Virtual Environment and install the required libraries:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

---

## The Pipeline workflow

### run_1: Download Google Speech Commands (Unknown)
Generates the baseline for the `unknown` class (other English words) to teach the network rejection.
```powershell
python run_1_download_google_data.py
```

### run_2: Download ESC-50 (Noise/Transients)
Generates the baseline for the `noise` class (ambient noise and sudden transients).
```powershell
python run_2_download_esc50.py
```

### run_3: Generate Synthetic Custom Keywords
Leverages Microsoft's ultra-realistic Edge Neural TTS to create hundreds of diverse vocal samples (multi-gender, multi-dialect, multi-age) for your custom target words. Outputs to the `custom_keywords` folder.
*(Note: If you want to use real-world recorded samples, manually create `wake_up` and `turn_on` folders inside `custom_keywords` and drop your `.wav` files in them).*
```powershell
python run_3_generate_synthetic_keywords.py
```

### run_4: Master Dataset Split
Automatically detects all files inside `custom_keywords` (both real and synthetic). Safely shuffles and copies 80% to `dataset/` (Training) and 20% to `dataset_test/` (Validation). This ensures neither real nor synthetic files cross-contaminate the datasets.
```powershell
python run_4_split_dataset.py
```

### run_5: Train Neural Network
Trains the custom 4-Class DS-CNN architecture (matching STM32 parameters exactly) using Keras. Outputs a `.h5` model file.
```powershell
python run_5_train.py
```

### run_6: Live PC Microphone Test
Loads the trained `.h5` model and connects to your PC microphone for immediate real-time testing. Includes the exact DC-offset and silence gate math used on the MCU.
```powershell
python run_6_mic_test.py
```

### run_7: TFLite INT8 Export
Converts the full `.h5` model into a completely quantized INT8 `.tflite` model, using a representative dataset generator to perfectly constrain activation margins.
```powershell
python run_7_convert_tflite.py
```

### run_8: Auto-Deploy to Firmware
Automatically searches for the C/H arrays generated by STM32Cube.AI Studio and places them directly into the main `Voice_Command_Assistant_STM32` project structure.
```powershell
python run_8_deploy_to_stm32.py
```
